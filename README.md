# MECH SURVIVOR

A fast, movement-first survivor prototype built around one core fantasy:

**THE RUN BUILDS THE MECH.**

## Controls

- Move: WASD / Arrow Keys / Left Stick
- Dash: Space / Shift / B / RB
- Auto-fire: automatic
- Pause: Escape / P / Start
- VFX Lab: F8 (Mac media-key layouts: fn + F8) or Command + Shift + V

## VFX Lab

The in-game SLU VFX Lab can preview registered combat effects directly on the active mech. Open it with F8 or Command + Shift + V on Mac, choose a recipe, adjust intensity, and press PLAY. While the panel is open, V replays the selected effect.

The VFX runtime is data-driven and currently includes particles, rings, flashes, streaks, arcs, beams, and procedural bolts, with Mech Survivor recipes layered on top.
